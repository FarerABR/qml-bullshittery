# qml-bullshittery

This repository is a small playground for experimenting with **quantum computing** and **quantum machine learning** ideas.

It currently contains a few simple experiments:

- `HHL/` – a notebook exploring the HHL algorithm.
- `cartpole-1/` – a notebook exploring classical RL and quantum RL ideas on CartPole.
- `entaglement/` – a tiny Python example that creates and measures a Bell state with Qiskit.

This project is mainly for learning and trying things out, not a polished library.
